# README 展示图规范

[项目 README](../../README.md) 的「界面预览」区域使用本目录下的 9 张展示图：

## 手机端界面

- `showcase-explore.jpg`：探索首页、每日推荐卡组与热门原创
- `showcase-catalog.jpg`：图鉴瀑布流（含主站译文 / 中文原创切换与系列筛选）
- `showcase-foundation.jpg`：基金会页签（RAISA 档案资质考核与设定手册入口）
- `showcase-stories.jpg`：故事目录、首字母索引筛选与「系列跟读」卡片
- `showcase-terminal.jpg`：终端首页、研究员档案工牌（含资质印章）与个人资料库
- `showcase-reader.jpg`：原生阅读器（阅读状态栏、原版网页切换提示、标签与配图）
- `showcase-archive-gallery.jpg`：三维档案馆与资源交付状态（内置 / 待下载）
- `showcase-archive-detail.jpg`：三维模型舞台（含底部 360° 自动旋转与复位控件）及档案详情

## 宽屏端界面

- `showcase-wide-split.jpg`：平板 / 折叠屏展开态 / 二合一设备的宽屏正文与研读侧栏（脚注、目录、关联故事）

## 后续更新建议

- 手机端展示图建议保持统一的画面尺寸、系统主题（浅色或深色一致）和状态栏处理，推荐宽度至少 `1080px`。
- 宽屏展示图建议同样保持主题统一，并在提交前遮盖通知、账号或设备标识等个人信息。

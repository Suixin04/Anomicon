## 三维控制栏与模型获取

API 26 模拟器加载生产控制栏，组合浅色与深色、材质开关和旋转开关，共 8 个状态。每个状态实际点击复位，8 次均收到回调。浅色模式下，自动旋转关闭时文字对比度为 **5.72∶1**，开启时 **6.73∶1**，复位 **10.44∶1**。父面板边界 **3.81∶1**，复位按钮边界 **4.75∶1**。深色模式的最低文字对比度为 **4.71∶1**。[八种状态的实测截图](archive-controls.png)

在三维修复提交 `f5c6220` 的隔离 Release 中，从 SCP-131 正文进入获取页，页面只展示该模型。下载 11.9 MB 后卡片显示“已下载”。点击“查看模型”回到查看器，再返回可见 SCP-131 原正文。任务暂停和续传用受控系统下载服务复验，重建仓库后沿用同一任务、令牌、路径和已有字节。[获取页截图](models-131-target.png) · [查看器截图](models-131-return.png) · [四步界面记录](models-device.json)

## 返修中实际拦住的问题

- 旧阅读器修复能找到长脚注，但深处的命中仍会跳到脚注首段。第二次提交在相同搜索结果内保留具体子块，测试覆盖了第 61 段、默认折叠段、重复词和跨段短语。[长脚注回归](branches/reader.md)
- 第一次离线修复会把失败的嵌入内文或缓存旧图装入新包。第二次修复能重验正文和同址配图，但图片由 PNG 改为 GIF 后，删除并重存副本还会取回旧 PNG。第三次提交在新图写入成功后清理旧格式。受控故障用例逐字节比较关闭数据库再打开后的图片。[磁盘和 SQLite 回归](branches/offline.md)
- 首版搜索修复在零后台配额下能补查一个系列，但首次返回 503 时，自动重试会排回后台。返修后，同一操作收到 503 后再取得 200，覆盖率从 1/15 升到 2/15，并命中 `SCP-1234`。其余系列仍在后台队列中。[弱网回归和旧版对照](branches/search-retry.md)

# 格异录 Anomicon Android 隐私政策

发布者为【与 Google Play 一致的运营者名称】。本政策自【生效日期】起适用。有关隐私、数据访问或删除的请求，可通过【可用的隐私联系邮箱或网页】联系我们。

## 设备上的阅读资料

应用无需注册格异录账号。阅读偏好、收藏、搜索和阅读历史、阅读位置、研读进度、考核结果、离线文章、下载模型和工单回执会保存在设备上，用于恢复你的阅读和设置。你可以通过应用提供的功能删除对应的记录或副本，也可以在 Android 系统设置中清除应用存储。设备上的数据是否进入 Android 备份或迁移受应用发行配置和设备设置影响。【发布前填写本版本的实际 Android 备份与迁移行为。】

## 阅读与资源下载

获取目录、正文、图片或下载模型时，应用会向 SCP Wiki、其图片等资源的提供方或 GitHub 的模型资源服务发出网络请求。请求会让相应服务看到访问地址、IP 地址和常规连接信息，用于提供内容。网页阅读会加载原网站页面及其引用的资源，网页提供方可能使用 Cookie 或依其政策处理访问数据。选择在系统浏览器打开链接时，后续浏览由相应网站及浏览器处理。[Wikidot 隐私政策](https://www.wikidot.com/legal:privacy-policy) · [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

## 你主动提交的 RAISA 工单

RAISA 用于反馈应用问题。填写后选择提交时，应用通过 HTTPS 将分类、简述、详细说明、应用版本、可选联络代号及你选定的附件发送至 RAISA 中转。中转使用请求标识避免重复建单，并使用连接 IP 限制过于频繁的请求。你可以在发送前预览诊断并关闭诊断选项。启用时，诊断会包含系统版本、窗口宽度、主题、工单入口，及从正文进入时的条目标识、标题、网址、阅读模式和反白透视状态。关闭后仍发送应用版本。

中转会在项目的 GitHub 仓库创建公开 Issue，并将附件保存在中转服务，在 Issue 中公布访问链接。工单正文、联络代号、包含的诊断和附件可能被任何人查看、下载或复制。请在提交前移除身份证件、私人联络方式、账号凭据或其他敏感信息。回执保存在设备上。清除设备上的回执不会更改已公开的工单。[公开 Issue 页](https://github.com/Suixin04/Anomicon/issues)

## 保存、删除与安全

设备数据通常会随你删除相应记录、清除应用存储或卸载而移除，设备备份和迁移以本政策前述说明为准。线上工单、附件和运行日志的保存期限或判断标准为【填写实际期限、附件清理、备份与日志安排】。通过本政策所列渠道提供工单号，可申请移除受我们控制的信息。被第三方保存的副本、缓存和平台记录可能由各方独立管理。工单和已核对的远程资源请求使用 HTTPS。三维查看器在设备内使用环回连接向查看器提供模型数据。

政策更新将通过【公开政策页及必要的更新通知方式】说明。有关访问、纠正或删除信息的请求，请联系本页所列渠道。
